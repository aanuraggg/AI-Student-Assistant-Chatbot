# AI-Powered Student Assistance Chatbot

## CA3 Project

**University:** Gopal Narayan Singh University  
**Course:** B.Tech 2nd Year — AI & ML

## Project Description
A web-based AI chatbot that helps students with academic questions, programming concepts, and general learning using Google Gemini AI.

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Google Gemini API

## Features
- Real AI-generated responses
- Modern responsive chat interface
- Multiple conversations
- Chat history using localStorage
- New Chat and Delete Chat functionality

## How to Run
1. Install Node.js.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run `npm install`.
5. Create a `.env` file containing `GEMINI_API_KEY=your_api_key`.
6. Run `node server.js`.
7. Open `http://localhost:3000` in your browser.
